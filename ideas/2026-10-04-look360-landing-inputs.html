C3 가격 공개 수준과 가격대 비용 페이지만 게시 차단

필요한 것: ① 공개 수준: 「공개 안 함 / 최소 금액만 / 지점 단가 구간」 중 하나 ② 공개한다면 실제 금액과 최소 제작 단위.

  • 비용 #factors 표 아래의 주황 자리표시([가격대 공개 여부 결정 후 채움])에 들어감. 공개하지 않기로 하면 이 자리표시를 지우고 「상담 후 견적」 문장으로 바꿈.
  • 대학교·초·중·고·공공시설 FAQ의 「비용은 어떻게 정해지나요 / 어느 정도인가요 / 견적서」 답변. 지금은 「지점 수에 따라 달라요 → 비용 페이지로」만 있음.
  • 절차 FAQ 「비용은 언제 정해지나요」 답변.
  • JSON-LD: 가격을 공개하면 Service에 offers.priceSpecification을 추가할 수 있음 (구글 검색 결과에 가격이 보일 수 있어).

C4 단계별 평균 제작 기간 절차 페이지만 게시 차단

필요한 것: 규모별로 상담부터 공개까지 걸리는 기간. 예: 소규모(5지점 이하) / 중규모(6~30) / 대규모(31 이상)에서 STEP별 영업일, 또는 전체 기간 범위. DB에는 근거가 없어.

  • 절차 #steps 소개 문단의 주황 자리표시([단계별 평균 기간 — 오너 확인 후 기입]), 각 STEP 옆에 기간 표시.
  • 절차 JSON-LD HowTo.totalTime.
  • 대학교 #process 다섯 단계 (선택: 입시 시즌 역산 일정 문구에 활용).
  • 검색어 「VR 투어 제작 기간」을 노리는 페이지라서, 기간 숫자가 없으면 이 페이지의 존재 이유가 약해져.

3. 사이트 단위 결정 (S1~S5)

항목필요한 결정어디에 쓰이나안 정하면
S1 사이트 안 링크 위치look360.kr에서 /solutions/ 허브로 거는 링크 위치: 상단 메뉴(「VR제작의뢰」 옆) / 푸터 / 메인 페이지 섹션 중 어디인지, 메뉴 이름레거시 레이아웃 layouts/look360/_cross/top.php(메뉴)·푸터·pages/main.php. 허브 페이지 /solutions/는 새로 만듦게시 차단 링크가 없으면 구글이 중요하지 않은 페이지로 봐서 사이트맵만으로는 순위가 잘 안 올라

S3 서치 콘솔 계정look360.kr이 등록된 구글 서치 콘솔·네이버 서치어드바이저 계정, 뮤뮤가 쓸 수 있는 권한이 있는지사이트맵 재제출, 랜딩 주소별 「색인 생성 요청」, 4주 뒤 성과 측정(기획 문서 6장)사이트맵에만 의존하게 돼서 색인이 몇 주 늦어질 수 있음
S4 문의 출처 집계 방식의뢰 버튼의 from=landing-xxx 값을 어떻게 셀지: GA4 페이지 주소만 볼지, 의뢰 게시판 글에도 저장되게 고칠지6장 전부의 의뢰 버튼, 레거시 게시판(pano_request) 저장 로직, 기획 문서 6장 성과 측정지금은 게시판 글에 출처가 남지 않아서 「어느 랜딩에서 의뢰가 왔는지」를 GA4로만 추정할 수 있음
