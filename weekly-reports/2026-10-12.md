## 🎬 360동영상 — 무엇을 만들었나 <span class="badge-date">10/8~10/11</span> <span class="badge-new">NEW</span>

| 영역 | 구현 내용 | 결과 |
|---|---|---|
| 서버(API) | 영상 테이블 신설 · 개별/일괄(zip) 매칭 업로드 · 읽기/쓰기 계약 | <span class="hl-green">QC 통과</span> (테스트 385/385) |
| 영상 변환 | ffmpeg 프리셋 스크립트 · 화질 단계와 기본 화질 하한 실측 | <span class="hl-green">완료</span> |
| 관리자 화면 | 등록·편집 탭 · 일괄 매칭 업로드 · 구성요소 종류 배지 | <span class="hl-green">QC 통과</span> |
| 사용자 뷰어 | 재생 레이어 · 화질 선택 · 종료 후 이동 · 첫 재생 통계 · 목록 배지 | <span class="hl-green">재QC 통과</span> |
| QC 결함 2건 | ① 화질을 바꿔도 실제 재생 소스가 그대로 ② 잠긴 영상의 원본 주소 노출 | <span class="hl-green">수정 후 재QC 통과</span> |
| 오너 결정 | 영상 장면 진입 시 자동 패닝 끄기 | <span class="hl-green">적용</span> |
