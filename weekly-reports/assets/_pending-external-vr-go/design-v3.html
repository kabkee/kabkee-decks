동작

  • vr-info 「사이트 이동하기」 클릭 → 새 창(새 탭)이 열리고 이 페이지가 먼저 뜸
  • 5초 카운트다운 → 0 에서 같은 창에서 외부 URL 로 이동 (location.replace — 뒤로가기 시 로딩 페이지로 안 돌아옴)
  • 「사이트 이동하기」: 카운트다운 무시하고 즉시 이동
  • 「취소」: 카운트다운 정지 후 새 창 닫기 (스크립트로 연 창이라 window.close() 가능 · 닫기 실패 시 vr-info 로 이동)
