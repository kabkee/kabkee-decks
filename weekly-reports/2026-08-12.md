## 해외 이용자 대응 — 자동 다국어 번역

콘텐츠를 여러 언어로 보여주는 구조를 새로 깔고, 사람이 다듬은 번역이 기계 번역에 덮이지 않도록 했습니다

## 🌐 자동 번역을 저장해 두고 다시 쓰는 구조 신설 <span class="badge-date">8/10~8/11</span> <span class="badge-new">NEW</span>

지금까지는 외국어 이용자가 콘텐츠를 볼 때마다 번역을 <span class="hl-red">매번 새로 돌려</span> 비용이 계속 나가고 결과도 그때그때 달랐습니다. 번역 결과를 전용 저장소에 보관해 두고 다시 쓰는 구조로 바꿨습니다.

| 항목 | 내용 |
|------|------|
| 번역 전용 저장소 신설 (IND-5687·5859) | 콘텐츠 번역문을 따로 보관하는 표를 새로 만들고 <span class="hl-green">기존 237행을 그대로 이관</span> |
| 저장·재사용 판정 (IND-5861) | 원문이 바뀌지 않았으면 저장해 둔 번역을 다시 사용하고, 동시 접속 시 같은 번역이 두 번 저장되지 않도록 방어 — <span class="hl-blue">오너 결정: 전량 일괄 번역이 아니라 「자동번역 버튼을 눌렀을 때만」 실행</span> (외부 번역 서비스 호출 비용 절감) |
| 사용자 화면까지 연결 (IND-5862·5871) | 실제로 쓰이는 상세 조회 경로가 번역을 아예 타지 않아 <span class="hl-red">이용자 도달이 0</span>이던 상태를 해소 |
| 언어코드 정합 (IND-5868) | 화면이 보내는 표기와 서버 내부 표기가 달라 <span class="hl-red">이미 저장된 140행을 전부 놓치던</span> 결함 수정 |
| 품질 구분 정책 (오너 확정 8/10) | <span class="hl-blue">자동번역 = 저품질 / 사람이 등록한 번역 = 고품질</span>로 구분해 저장하고, 기존 등록분은 전부 사람 번역으로 취급 |

## 🏷️ 「자동 번역본」임을 화면에서 바로 알 수 있게 — 오너 표기 규칙 확정 <span class="badge-date">8/10~8/11</span> <span class="badge-new">NEW</span>

영어 사이트에 들어가도 제목·설명이 <span class="hl-red">한국어 그대로 나오던</span> 결함을 잡고, 이용자가 「이건 자동 번역본」임을 화면에서 즉시 구분할 수 있도록 표기 규칙을 오너가 직접 확정했습니다.

<div class="cols">
<div class="col">

### 무엇이 문제였나

- 영어 사이트에서 제목·설명이 <span class="hl-red">한국어 원문 그대로 노출</span> (IND-5872·5873)
- 같은 장소를 다른 언어로 따로 만들어 둔 콘텐츠를 찾아갈 방법이 없음
- 화면에 보이는 문장이 자동 번역인지 사람이 쓴 원문인지 구분 불가

</div>
<div class="col">

### 오너가 확정한 표기 규칙

- 언어 표시는 <span class="hl-blue">「한국어 → 日本語(Auto)」</span> 형식 — 사람이 넣은 번역이면 (Auto) 없이 「한국어 → 日本語」로만 표시 (IND-5861)
- (Auto) 칩 배경은 <span class="hl-blue">브랜드 형광색으로 고정</span> — 오너가 목업을 2회 반려하며 확정했고, 실제 화면과 동일한 예시를 상세 페이지에 구현해 확인
- 다른 언어로 만들어진 별도 콘텐츠는 상세 화면 탭 위 <span class="hl-green">「다른 언어 콘텐츠」 섹션</span>에 카드로 노출 (IND-5860·5864)
- 언어 배지 색상을 <span class="hl-green">6개 지점에 동일 적용</span>하고, 표시 언어 기준을 사이트 언어로 정정 (IND-5863)

</div>

## 🔒 유료 콘텐츠 무단 노출 차단 — 이번 주 최우선 보안 작업 <span class="badge-date">8/7~8/10</span>

## 💳 결제·구매 화면 — 금액 표기 정정과 오픈 대기 항목 <span class="badge-date">8/7~8/10</span>

금액 앞에 <span class="hl-red">정체불명의 「c」</span>가 붙고, 일본어·중국어 화면에서는 <span class="hl-red">원화 금액이 円·元으로 표기</span>되고 있었습니다.

| 항목 | 내용 |
|------|------|
| 통화 기호 정정 (IND-5709) | 금액 기호 c → <span class="hl-green">원화(₩)로 전역 치환</span> + 공통 금액 표기 함수 신설. 일본어·중국어 화면의 円/元 오표기 13곳 정정 (IND-5792·5794) |
| 구매 내역 카드 (IND-5710) | <span class="hl-green">최저가 배지</span>와 「결제금액 : {금액} ({구매일자})」 라인 추가, 탭 라벨을 「감상가능」으로 변경 (IND-5804·5805·5806·5808) |

## 👤 나의 기록·나의 활동 — 일반 목록과 같은 규격으로 통합 <span class="badge-date">8/6~8/11</span> <span class="badge-new">NEW</span>

<div class="col">
