## 뷰어 미디어 UX — 라이트박스

화면마다 제각각이던 라이트박스를 하나로 통합하고, 확대·캡션 경험을 완성했습니다

---

## 라이트박스 4종 구현 통합 + 리사이즈 래칫 근본 수정 <span class="badge-date">7/20~7/21</span>

vr-info 갤러리·파노라마 갤러리·VRSTORY·리뷰 4곳이 <span class="hl-red">서로 다른 라이트박스 구현</span>을 쓰던 것을 정본 하나로 통합했습니다.

| 항목 | 내용 |
|------|------|
| 구현 통합 | MediaLightbox.vue 삭제 — 4개 화면이 ImageGalleryModal 정본을 공유 (구현 2종으로 축소) |
| 래칫 버그 | 창 크기 조절 시 이미지가 계속 작아지던 문제 — 측정→고정 방식 폐기, <span class="hl-green">shrink-wrap 레이아웃</span>으로 근본 수정 |
| 메타 줄 (B안) | 캡션·카운터를 오버레이 대신 <span class="hl-blue">이미지 하단 메타 줄</span>로 부착 — 사진을 가리지 않음 |
| 영상 폭 | iframe 영상이 좁은 화면에서 넘치던 문제 — 컨테이너 폭 단위(cqw)로 실폭 추종 |

- 검증: 4개 뷰포트(390/800/1200/1440px) × 5개 매체(가로/세로/4:1 파노/YouTube/Vimeo) — <span class="hl-green">20/20 QC 매트릭스 PASS</span>

## 잠금 판정 3계층 규칙 <span class="badge-date">7/19~7/20</span>

어드민 판매설정과 실제 뷰어 노출이 <span class="hl-red">서로 어긋나던 문제</span>를 규칙 엔진 재설계로 해소했습니다.

| 계층 | 규칙 | 예 |
|------|------|-----|
| 1. 콘텐츠 기본값 | 콘텐츠 단위의 기본 공개/잠금 | 유료 콘텐츠는 기본 잠금 |
| 2. 판매상품 override | 판매상품 설정이 기본값을 덮어씀 | 미리보기 포함 파노는 공개 |
| 3. 개별 파노 예외 | 파노라마 단위 예외 지정이 최우선 | 특정 파노만 잠금/공개 |

- 갤러리·스와이프·딥링크 등 <span class="hl-blue">전 표면 동일 규칙 적용</span> — 우회 경로로 잠긴 파노에 접근 불가
- BE 규칙 엔진 + 뷰어 표면 적용 + 통합 QC, 자식 5건 전부 완료
