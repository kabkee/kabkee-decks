## 판매자 스튜디오<br>(Creator Studio)

콘텐츠를 파는 창작자를 위한 전용 관리 공간 신설

---

## 판매자 스튜디오 — 4개 화면 신설 <span class="badge-new">NEW</span>

VR 콘텐츠를 판매하는 창작자가 <span class="hl-blue">판매·수익·방문 현황을 스스로 관리</span>하는 전용 공간을 신설했습니다. 마이페이지에서 진입합니다.

| 화면 | 경로 | 기능 |
|------|------|------|
| 콘텐츠 관리 | `/studio/contents` | 내 판매 콘텐츠 목록 + 콘텐츠별 리워드(보상) 설정 |
| 수익 관리 | `/studio/revenue` | 판매 수익 현황 조회 |
| 방문 통계 | `/studio/analytics` | 콘텐츠별 조회수·방문 분석 대시보드 |
| 판매자 알림 | `/studio/notifications` | 판매·리뷰 관련 알림 모아보기 |

- 좌측 내비게이션에 <span class="hl-green">판매자 진입 버튼</span> 추가 — 일반 사용자/판매자 화면 분리
- 방문 통계는 신규 방문 이벤트 수집 기반으로 실데이터 집계

## 알림 센터

플랫폼 활동을 사용자에게 실시간으로 알리는 알림 체계 구축

---

## 알림 센터 — 헤더 팝업 + 알림함 + 설정 <span class="badge-new">NEW</span>

구매·판매·리뷰 등 플랫폼 활동을 사용자에게 전달하는 <span class="hl-blue">통합 알림 체계</span>를 처음으로 구축했습니다.

<div class="cols">
<div class="col">

### 알림 확인

- 헤더 종 아이콘 팝업을 <span class="hl-teal">일반 / 판매자 탭</span>으로 분리
- `/my/notifications` 전용 알림함 페이지 신설
- 알림 클릭 시 관련 콘텐츠·구매내역으로 바로 이동

</div>
<div class="col">

### 알림 설정

- `/my/settings/notifications` 수신 설정 페이지
- <span class="hl-amber">유형별 × 채널별</span> 수신 on/off
- 설정 반영해 실제 발송을 거르는 게이트 적용

</div>
</div>

> 콘텐츠 판매·리뷰 작성·이용권 만료 임박 등 상황별 알림을 발송 (총 7종 알림 유형)

## 유료 콘텐츠<br>판매 · 만료

무료로 새던 유료 콘텐츠를 촘촘히 게이팅하고, 구매 흐름을 매끄럽게

---

## 유료 뷰어 차단 → 즉시 구매 전환 <span class="badge-date">6/30~7/3</span>

미구매 사용자가 유료 콘텐츠에 접근하면 <span class="hl-red">막다른 차단 화면</span> 대신, 콘텐츠를 안내하고 <span class="hl-green">바로 구매로 이어지는 카드</span>를 보여주도록 개편했습니다.

| 항목 | 이전 | 이후 |
|------|------|------|
| 미구매 접근 | 단순 차단 | 콘텐츠 안내 카드 + 즉시 구매 버튼 |
| 구매 직후 | 새로고침 필요 | 자동으로 뷰어 다시 로드 |
| 대표 이미지 | 없을 때 빈 화면 | 첫 파노라마 썸네일로 폴백 |

- 임베드(외부 삽입)로 우회 접근하던 유료 콘텐츠 차단 보강
- 파노라마 목록에서도 <span class="hl-blue">유료·미구매 항목의 썸네일·제목 잠금</span> 처리

---

구매한 이용권의 <span class="hl-amber">만료 기간</span>을 도입하고, 만료 시 사용자 경험을 정돈했습니다. (이천농나드리 채널 정합화 과제에서 출발)

<div class="col">

### 만료 처리

- 상세 페이지에 <span class="hl-red">만료 안내</span> + 재구매 버튼
- 뷰어 상단 만료 배너 노출

</div>
<div class="col">

### 함께 복구한 것

- 채널 프로필 이미지 깨짐 복구
- 판매 대상(유료) 콘텐츠 노출 조건 정비
- 만료 콘텐츠의 통계 오집계 방지

</div>

## VRSTORY 뷰어 — 재생 품질 전면 복원 <span class="badge-date">6/30~7/5</span>

레거시에서 이관되며 누락됐던 <span class="hl-blue">VR 스토리투어 재생 기능</span>을 전수 복원하고 안정화했습니다.

| 복원 기능 | 내용 |
|-----------|------|
| 인플레이스 동영상 | 파노라마 안에서 동영상(livepano)이 실제로 재생되도록 복구 |
| 스토리 핫스팟 | 시작/다음 장면으로 넘어가는 구면(球面) 버튼 복원 |
| 배경 음악 | 배경음악 별도 on/off 제어 버튼 추가 |
| 공통 스킨 | 이관 중 빠진 아이콘·효과·동작 전수 복원 |

- 화면에 남아있던 디버그(개발용) 오버레이 제거 — 뷰어 위생 정리

## 리뷰 작성 흐름 단순화 <span class="badge-date">7/2~7/3</span>

여기저기 흩어져 헷갈리던 <span class="hl-red">리뷰 진입점을 하나의 버튼으로 통합</span>하고, 리뷰를 쓸 수 있는 사람만 버튼을 보도록 정리했습니다.

<div class="cols">
<div class="col">

### 진입점 통합

- 상세 페이지의 리뷰 안내 배너 5종 → <span class="hl-green">단일 "리뷰 작성" 버튼</span> 1개로 통합
- 리뷰 작성 불가 상태면 버튼 자체를 숨김

</div>
<div class="col">

### 자격 정비

- 콘텐츠당 1회 리뷰 원칙 정립
- 관람 조건(구매·이용권)을 갖춘 사용자만 작성 가능
- 비로그인 사용자는 로그인 후 이어서 작성

</div>
</div>
