## VRSTORY 엔진 3·4차 개조 + 씬 딥링크 <span class="badge-date">7/6~7/7</span>

레거시 스토리투어의 재생 동작을 재현하는 엔진 개조를 마무리하고, <span class="hl-green">특정 장면으로 바로 진입하는 공유 URL</span>을 지원합니다.

| 항목 | 내용 |
|------|------|
| 씬 딥링크 | `/vr/{도메인}/{챕터}-{장면}` URL로 특정 장면 직접 진입·공유 |
| 챕터 목록 | 2단 아코디언 구조 + 장면(item) 단위 이동 |
| 재생 안정화 | 씬 전환 시 잔여 효과 정리, 인플레이스 동영상(livepano) 체인 복원 |
| 시선 이동 | lookTo 줌인 멈춤·씬 전환 후 줌 잔존(fov) 버그 수정 |

- door(문 이동) 핫스팟의 비동기 실행 순서 보장 — 클릭 시 줌인 후 자연스러운 씬 전환

## 골든 스토리 회귀 테스트 인프라 <span class="badge-date">7/9</span> <span class="badge-new">NEW</span>

| 항목 | 내용 |
|------|------|

| 커버리지 | 1번째 골든 스토리 74개 체크포인트 + 2번째 스토리 스펙 착수 |
| 운영 규정 | 엔진 코드 변경 시 골든 회귀 통과를 머지 게이트로 규정화 |
| 검증 | 의도적 회귀 주입 시 테스트가 실제로 잡아내는지 검출력 증명 완료 |

## 구매확정 게이트형 포인트 적립 <span class="badge-date">7/8</span> <span class="badge-new">NEW</span>

구매 즉시 적립하면 <span class="hl-red">환불 시 이미 쓴 포인트를 회수할 수 없는</span> 사고 여지가 있어, 적립을 지연 확정하는 구조로 설계했습니다.

| 항목 | 내용 |
|------|------|
| 적립 흐름 | 구매 → 적립 대기(pending) → 관람 확정 또는 7일 자동확정 시 지급 |
| 환불 처리 | 확정 전 환불이면 적립 자동 취소 — 회수 불가 사고 원천 차단 |
| 정책 통일 | 판매자별 개별 적립률 폐기 → 전역 정책 + 콘텐츠별 관리자 override |
| 사용자 화면 | 마이페이지 적립금 위젯 (대기/확정 구분 표시) |

- 변경 이력을 남기는 감사(audit) 테이블 도입 — 정책 변경 추적 가능
