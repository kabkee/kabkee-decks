## 🧭 작업 순서 — 작성자 → 검수자 → 오너 <span class="badge-date">상시</span>

| 단계 | 담당 | 할 일 |
|---|---|---|
| ① 배정 | 관리자 | 장소별 작성자·검수자 지정 (작성자 12명 · 검수자 7명 활성) |
| ② VR 장면 | 작성자 | 사진을 보며 🟡 확인 — 일괄 확인 가능, 단 자동 검사에 걸린 문장은 1건씩 |
| ③ 장소 정보 | 작성자 | 추천 문구 가져오기 → ⬜ 채우기 → 🟡 확인 → 제출 |
| ④ 검수 | 검수자 | 작성자와 다른 사람이 읽고 확정(작성자 본인은 확정 불가) |
| ⑤ 반영 | 오너 승인 | 확정된 글만 묶음 단위로 레거시 반영(dry-run 먼저) |

- VR 장면과 장소 정보는 **따로 확정·반영**됩니다. 한쪽이 끝나지 않아도 다른 쪽은 진행할 수 있습니다.
- 진행 순서는 AI 생성과 같습니다: 서치 콘솔 클릭 → 노출 → 레거시 조회수가 높은 장소부터.

## 🔍 확인할 때 특히 볼 것 — AI가 자주 틀리는 유형 <span class="badge-date">표본 확인</span>

| 유형 | 예시 | 확인 방법 |
|---|---|---|
| 사진 속 글자 오독 | 서핑 매장 로고를 «GWANG BEACHAN»으로 읽음 | 간판·로고 글자는 사진 확대로 대조 |
| 색·재질 단정 | 회색 돌기 타일을 «노란 바닥 타일»로 씀(QC 표본) | 애매하면 문장에서 빼기 |
| 문장 잘림 | 마지막 문장이 마침표 없이 끝남 | 끝 문장 읽어 보기 |
| 오래된 정보 | ✅ 문장도 외부 자료 기준이라 운영시간 등이 바뀌었을 수 있음 | 공식 사이트로 재확인 |

- 장면 설명은 4방향 사진(앞·오른쪽·뒤·왼쪽)을 보고 썼습니다. **사진에 보이는 것만** 남기고, 장소 이름에서 추측한 내용은 지웁니다.
- 일괄 확인을 눌러도 기록(누가·언제·일괄)이 남고, 검수 화면에서 «일괄 확인 비율»이 보입니다.
