STEP 3 가입 · 승인

초대받은 이메일로 가입 → 승인되면 회사 항목이 보여요

  1. 개발팀장이 내 이메일로 조직 초대
    초대 메일은 따로 오지 않아요
  2. 로그인 화면의 [계정 만들기] 에서 초대받은 그 이메일로 가입
  3. 마스터 비밀번호 정하기 (12자 이상)
  4. 개발팀장이 승인하면 회사 컬렉션이 나타나요

🔑 마스터 비밀번호는 잊으면 아무도 복구할 수 없어요. 개발팀장도 못 찾아요. 다른 곳에서 쓰지 않는 긴 문장형을 추천해요.

STEP 3 가입 직후 꼭

2단계 인증(인증 앱)을 켜 주세요

  1. 웹에서 설정 → Security → 2단계 로그인
  2. 인증 앱 옆 [관리] → 마스터 비밀번호 확인
  3. 폰의 인증 앱(Google Authenticator 등)으로 QR 스캔
  4. 앱에 뜬 6자리 입력 → [활성화]
  5. 복구 코드도 확인해서 안전한 곳에 적어 두기
