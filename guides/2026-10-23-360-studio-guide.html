① 자동 정렬

버튼 하나로 사진 위치·렌즈를 맞춰

자동 정렬 실행

특징점으로 사진끼리 맞춰. 순서가 섞이거나 천정 샷이 있어도 돼. 장면당 수십 초~몇 분

RAW(NEF) 장면

보라색 RAW 배지. 올리자마자 자동 현상하고, 「현상」에서 RAW / JPG 그대로를 고를 수 있어

끝나면

미리보기를 만들고 ② 검수로 넘어가. PTGui 로 넘길 땐 pts 내보내기도 있어

② 검수·조정

미리보기에서 이음매를 확인해

빨강 어긋남

겹치는 두 사진이 서로 다르게 보이는 곳. 시차·움직인 사람

주황 밝기 차

이음매 양쪽 밝기 차이. ±0.15스톱이 넘으면 표에서 주황으로 강조

사진별 각도·노출 표

yaw·pitch·roll 을 0.05° 씩, 노출(EV)을 0.05스톱 씩 고쳐

저장하고 다시 보기

몇 초 뒤 갱신. 위쪽에 남은 시간, 바뀐 곳은 하늘색으로 잠깐 깜빡

평면 / 360° 를 바꿔 볼 수 있어. 평면에서는 휠로 확대, 드래그로 이동, 더블클릭으로 원래대로.

② 톤·색

그늘은 살리고 하늘은 지키는 「정보성」 톤

순서

  1. 프리셋 ★「정보성 VR」을 골라
  2. 섀도·하이라이트·국소 압축으로 다듬어
  3. ⊕ 회색 찍기: 흰 벽·회색 바닥을 눌러 색 맞춤
  4. 「저장」 → ④ 최종 렌더에 들어가

RAW 장면

선형 데이터라 살릴 폭이 넓어. 하얗게 날아간 곳 0.99% → 0%

JPG 장면

이미 구워진 사진이라 폭이 좁아. 날아간 곳은 못 살려

내 프리셋

이름을 붙여 저장하면 모든 장면·작업자가 같이 써

③ 마스크

겹치는 곳에서 어느 사진을 쓸지 칠해

초록 = 꼭 써

빨강 = 쓰지 마

움직인 사람, 삼각대, 그림자가 찍힌 쪽

저장 = 자동 반영

저장하면 ② 미리보기가 몇 초 만에 다시 만들어져

⬇ 포토샵

펴진 사진을 받아 고친 뒤 끌어다 놓기

  1. 360 화면에서 고칠 곳을 가운데에 크게 (확대할수록 선명) → 「🩹 이 화면 리터치」
  2. 그림자·반사까지 넉넉하게 칠하기 (점선 = 칠한 범위)
  3. 「원래 사진 보기」를 누르고 비교 → 「✓ 적용」 = 레이어로 저장 (끄기·지우기 가능)

⑥ 모자이크

2

마침표(.)·쉼표(,) 키로 후보를 하나씩 넘겨 보며 틀린 건 지우기

3

빠진 건 사각·타원·자유곡선으로 직접. 「다음 시점」으로 빠짐없이 훑기
